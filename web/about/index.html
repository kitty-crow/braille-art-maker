How it works

PNG to Unicode.

Vectorise

The pinned Vectoriser converts the source to path-only SVG with cropping disabled. Unicode Art Studio rasterises that SVG for the remaining stages.

Tone and dither

The image is resized to the Unicode dot grid, converted to alpha-aware luminance, stretched and sharpened. Ordered 4×4 with inverted polarity is the monochrome default; Atkinson, Floyd-Steinberg and threshold modes are also available. Colour mode defaults to Atkinson.

Colour

Foreground colour samples source pixels represented by raised dots. Background colour can separately preserve off-dot pixels. Full colour can treat each 2×4 cell as a two-colour tile, grouping the eight source samples perceptually and using the grouping to choose the Unicode character.

Pack and render

Each 2×4 binary block maps to one Unicode character. The dense renderer measures the active font and fixes cell geometry to a 1:2 character ratio. Colour TXT uses foreground/background tags and self-contained HTML writes colours directly into the cells.
